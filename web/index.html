ZipCheckup Agent US home environmental risk, callable by an agent

A page an agent can operate, not just read.

This page registers WebMCP tools with your browser, so an assistant can query US environmental-risk data for all 42,679 ZIP codes by calling functions here instead of scraping the screen - and can write to the shortlist below, where you watch it happen. The same federal records are published as free, human-readable reports at ZipCheckup.

Every value carries its source, its snapshot date and the legal threshold it is judged against. Values missing from the source come back as an explicit unknown with a reason, never as a reassuring zero. On drinking-water data that distinction is the product.
